One haiku about debugging, three lines in the 5-7-5 syllable shape: a cursor blinking at three in the morning, a log line that lies, calm and still — and dawn finding the lost brace. The program writes the haiku (82 characters) to `/output/entry.txt`, checking it against the competition gate (1–200 characters, not only whitespace; exactly three lines) before writing.

## Run it

```sh
ENTRY_OUTPUT=./entry.txt node main.ts
```
